# 预算追踪器 - Agent Team 任务

## 目标
构建一个功能完整的个人预算追踪单页应用 (SPA)。

## 需求
1. **index.html** — 主页面，包含：
   - 收入/支出表单（金额、类别、日期、备注）
   - 交易列表（可删除）
   - 余额显示
   - 总收入和总支出统计
2. **app.js** — 逻辑代码，包含：
   - 添加交易
   - 删除交易
   - 计算余额
   - localStorage 持久化
3. **style.css** — 样式文件，简洁现代的 UI
4. 所有文件放在 `/Users/qi/Desktop/测试文件夹/` 中

## 验收标准
- 打开 index.html 可以看到完整的预算追踪界面
- 可以添加、删除交易
- 余额自动计算
- 刷新后数据保留
- 界面美观可用
