# BudgetLoop v0.3.1

BudgetLoop v0.3.1 is the verified unified Web, backend, macOS, and Windows release built from one immutable tag.

## Highlights

- Agent Team startup reports queued, workspace preparation, agent startup, running, warning, and terminal failure states instead of leaving the operator with an unexplained wait.
- Repeated OpenHands workspace startup failures are bounded, preserved as actionable diagnostics, and end in an honest failure state.
- The startup activity mark is visible, reduced-motion aware, non-duplicative for assistive technology, and paired with a live elapsed wait indicator.
- Web, backend, macOS, Windows, Tauri, and Rust package metadata all report `0.3.1` and are checked automatically.
- The primary README is English-first, with a separate complete Simplified Chinese document.
- macOS and Windows desktop artifacts are built from this tag after Web, backend, version-parity, and native-platform gates pass.

## Release-candidate correction

The unpublished `v0.3.0` candidate stopped at its clean Linux verification gate. v0.3.1 narrows the runtime artifact ignore rule so the backend ArtifactStore package is tracked and declares LiteLLM/pytest-asyncio as reproducible test dependencies. The failed tag was not moved or published as a Release.

## Downloads

- `BudgetLoop-v0.3.1-macos.zip` — macOS 13+ native launcher.
- `BudgetLoop-v0.3.1-windows-x64.msi` — Windows 10/11 x64 native launcher.
- `SHA256SUMS` — SHA-256 digests for both desktop artifacts.

The Web application and backend are delivered from this tag through Docker Compose.

## Requirements

Both desktop launchers require Docker Desktop and a local BudgetLoop `v0.3.1` checkout containing `docker-compose.yml`. They do not bundle Docker, source repositories, model credentials, or database contents.

- macOS: macOS 13 or later. The archive is ad-hoc signed but not Apple-notarized; the first launch may require an explicit Open confirmation.
- Windows: Windows 10/11 x64, Docker Desktop, and Microsoft Edge WebView2 Runtime. The MSI is not Authenticode-signed, so SmartScreen may report an unknown publisher.
- Model execution: configure an authorized New API or compatible server-side gateway in `.env`.
